# Aniimo Egg Heist Loot Tables

Fan-made reference for Aniimo's **Operation: Egg Heist**: what each mode (PvP, Normal, Hard, Nightmare, Chaos) can drop, including eggs, containers, enemies, loot pools, rank rewards, daily chests and Display Case milestones, compiled from the game's client data files.

Live page: https://sargeeva.github.io/aniimo-egg-heist-loot/

Drop rates aren't included: the odds and the main loot of chests, egg nests and bosses are rolled on the game's server.

- `index.html` — the page
- `assets/` — item icons and mode art extracted from the game (WebP)

Companion site: [Aniimo Friendship Guide](https://sargeeva.github.io/aniimo-friendship-guide/)
